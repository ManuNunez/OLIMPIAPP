# OLIMPIAPP
OLIMPIAPP is a project designed to help users participate in and manage their involvement in the Regional Mathematics Olympiad of Chapala (OMRCh). This application provides tools for registering, tracking progress, and accessing information about the competition.

## Features

- **User Registration**: Sign up as a student, coach, or both.
- **Event Management**: View and manage events related to the OMRCh.
- **Training Sessions**: Access information about training sessions and their schedules.
- **Contact Information**: Easily find contact details for committee members and organizers.
- **Legal Notices**: Read and understand the legal terms and conditions.

## Installation

To install and run OLIMPIAPP locally, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/ManuNunez/OLIMPIAPP.git
    ```
2. Navigate to the project directory:
    ```bash
    cd OLIMPIAPP
    ```
3. Create a virtual environment and activate it:
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```
4. Install the dependencies:
    ```bash
    pip install -r requirements.txt
    npm install
    ```
5. Start the application:
    ```bash
    flask run
    ```

## Usage

Once the application is running, you can access it in your web browser at `http://localhost:5000`. From there, you can create an account, register for events, view training schedules, and access other features.
